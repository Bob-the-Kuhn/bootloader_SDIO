Below are routines used to verify the clocks were configured properly.

The HAL_xxxx routines were advertised as reporting how the clocks were actually working.  They 
never gave believable results.  Some of that is because thee value for HSE_VALUE is set by the
HAL_xxxx level files multiple times.  I tried "#ifdef ..." sequence to force the correct value
but the HAL_xxxx routines were always strange.  Efforts to print the run time value of HSE_VALUE
sometimes gave 16MHz and sometimes 25MHz.  The only way I got a 12MHz printout is if the print 
statement came within the same file as the declaration and the none of the HAL_xxxx routines were
called between the two.

In the end I measured the baud rate on USART1 to determine if some of the clocks were setup
properly.

void print_binary_u32(uint32_t num) {
    // Loop through all 32 bits, starting from the Most Significant Bit (MSB)
    for (int i = 31; i >= 0; i--) {
        // Shift right by i, then isolate the lowest bit using bitwise AND
        uint32_t bit = (num >> i) & 1;
        sprintf(msg,"%1u", bit);
        print(msg);

        // Add a visual space after every 4 bits, except after the last bit
        if (i % 4 == 0 && i != 0) {
            print(" ");
        }
    }
    print("\n");
}
